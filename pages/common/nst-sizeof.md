# nst-sizeof

> Show the size of a file or folder.
> More information: <https://github.com/shub-nova/tldr>.

- Show the total size of a file or folder:

`nst-sizeof {{path/to/file_or_folder}}`

- Show the size in a human-readable format (for example `4.2M`):

`nst-sizeof --human {{path/to/file_or_folder}}`

- Show the size in bytes:

`nst-sizeof --bytes {{path/to/file_or_folder}}`
